# ndruster-repository-classification
完整的仓库分类索引 - 对 ndruster 账户所有仓库进行 3 级分类

## 1. 目标

该仓库用于系统性整理 `ndruster` 账号下公开仓库的主题结构，按三层分类方式维护：

- L1：大主题
- L2：子领域
- L3：具体项目类型 / 实现方向

目标是让仓库集合更容易理解、维护和扩展，并作为后续目录筛选和项目规划的统一入口。

## 4. 归档结论

从目前的仓库分布看，`ndruster` 的仓库主题呈现出明显的多领域混合特征，核心集中在：

- AI / Agents / LLM / Memory / Workflow
- Game Tech / Strategy / Modding / Multiplayer
- Infra / Platform / Desktop / Terminal tooling
- Systems / Network / Security / Reverse engineering
- Quant / Forecast / Research / Data science
- Learning / Resource / Architecture / Curated references

整体上这是一个“AI + 游戏 + 工程 + 安全 + 研究”并重的技术栈图谱。

## 5. 后续维护建议

- 新增仓库时优先按 L1/L2/L3 归档
- 保持分类标准一致，避免过度碎片化
- 每季度检查一次主题分布并更新索引
- 对特别大型项目单独留出更详细的 README 或子目录说明
